# 和远智能端到端验收剧本

## 前置

```bash
# 1) Docker 依赖
docker compose up -d db minio

# 2) 材料规范化 + 模板工程化 + 导入
./.venv/bin/python scripts/import_heyuanzhineng.py --force

# 3) 启动本机后端
./scripts/dev_mac.sh
```

前端：http://localhost:3000  
基础数据管理：http://localhost:3000/admin （各模块独立 URL）

## 剧本

1. **工程化模板1**  
   新建标书 → 选「铁路工程投标模板1-工程化」→ 确认字段（改正脱敏项）→ AI 生成 → 选营业执照/资质 → 校验 → 导出 DOCX。

2. **工程化模板3**  
   同上，选模板3，项目类型填 RTU。

3. **历史标书智能替换**  
   选一份历史标书（非招标文件）→ 修改项目名称/编号 → 导出，确认封面关键信息已变。

4. **基础数据管理（Admin）**  
   - `/admin/company`：修改企业电话 → 新建项目确认预填已更新  
   - `/admin/qualifications`：新增/编辑资质、预览附件、修改有效期  
   - `/admin/checklist`：按 tpl1 筛选，新增/编辑条目  
   - `/admin/templates/:id/preview`：系统内查看模板正文（PDF 分页 / 正文结构）
   - `/admin/templates/:id`：查看占位符列表、下载 DOCX  
   - `/admin/faqs/:id`：修改 FAQ → Chatbot 命中新答案  
   - `/admin/import`：导出 JSON 备份；必要时强制重导并确认向导数据刷新

5. **红灯阻断**  
   故意不选必附资质 / 留空项目名称 → 校验或导出应失败。
